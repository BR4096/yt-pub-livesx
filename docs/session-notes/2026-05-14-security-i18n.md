- Full i18n: ~30 files translated Portuguese → English via 6 parallel agents; variable names/paths/keys unchanged

**Key decisions:**
- Password hashing (bcrypt) deferred — acceptable behind SSH tunnel, flagged in BACKLOG
- `dashboard/` has no `__init__.py` → namespace package on Python 3.14; `__file__` is None at package level but is set on `server.py` module itself
- AI prompts translated to English (operators read them; AI output language governed by explicit instructions in the prompts, not the prompt language)
- Two-stage review per task (spec compliance → code quality) run via subagent-driven-development skill

**Gotchas found:**
- `db.py` caches SQLite connection in `threading.local()` — must call `db.close_db()` before AND after yield in pytest autouse fixture or stale handles pollute tests
- `patch.object(srv, '__file__', str(tmp_path / 'server.py'))` redirects `os.path.dirname(__file__)` lookups in tests without writing to the real source tree
- `import shutil` inside a method body is a style violation when it's already at module level — two stale local imports survived in `scheduler.py` until code review caught them
- `exit 0` on user cancellation in bash scripts is wrong; should be `exit 1` to signal abort to automation
